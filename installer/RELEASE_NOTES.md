Build of Search for Windows. It still carries the original name and icon, which belong to Office Commun: rename before sharing it widely.

**Install:** download `Search-Setup-…-x64.exe` and run it. It installs for your Windows user only, with no admin prompt. Windows SmartScreen will warn because the installer isn't signed: choose **More info › Run anyway**.
**No install:** unzip `Search-win-x64-portable.zip` and run `Search.exe`.

**What works:** sidebar with pins and tabs, new-tab address field with history suggestions, Ctrl+L to edit the address, session restore, Ctrl shortcuts, light/dark following Windows, and Search under Settings › Apps › Default apps.

**Updating:** Search checks for a newer release at launch and every hour, downloads it quietly, and shows "Restart to Update" at the foot of the sidebar. You can also check from the window menu (Alt+Space › Check for Updates…).
